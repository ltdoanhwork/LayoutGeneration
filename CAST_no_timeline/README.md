# CAST_loss — Anchor-First Voronoi Layout

Shape-aware video collage generation via weighted anisotropic power diagram with
a three-loss optimization framework.

---

## Method Overview

Each keyframe is assigned a guaranteed **anchor core** region inside the target
shape before gradient descent begins.  The remaining foreground area (the *free
shell*) is competed for via an anisotropic power diagram optimized with three
complementary losses.

```
input frames + shape mask
        │
        ▼
[Anchor initialization]  medial-axis sites, disjoint core regions
        │
        ▼
[Phase 1 — Gradient optimization]  50 iters, 3-loss objective
        │
        ▼
[Phase 2 — Polygon extraction]  high-res rasterize → orphan reassignment
                                → merge passes → polygon buffering
        │
        ▼
[Content-aware warp + collage assembly]
```

---

## Three Loss Functions

### L\_cap\_res — Residual Capacity Matching

```
L_cap = mean( (free_area_i  −  target_residual_i)² )
```

**Goal**: Match each cell's free-shell area to the frame's saliency-based
target, minus the pre-allocated anchor core.

**Enabled in**: `full`, `wo_cvt`, `wo_fea`

**Effect of removing (`wo_cap`)**: All cells converge to equal size regardless
of how large or small the subject in each frame is.  The collage loses
content-proportional layout — an important photo with a large face gets the
same cell as a background shot.

**Most visible in**: `test_cap` (varying subject sizes in a star shape)

---

### L\_cvt\_norm — Normalised Centroidal Regularity

```
L_cvt = mean( ||site_i − centroid_i||²  /  (√area_ratio_i + ε) )
```

**Goal**: Pull each site toward its cell's area centroid, making cells compact
and non-wandering.  The inverse-sqrt area weighting focuses gradient on small,
at-risk cells.

**Enabled in**: `full`, `wo_cap`, `wo_fea`

**Effect of removing (`wo_cvt`)**: Sites drift away from cell centroids.
Cells become elongated, irregular polygons — especially in corners and narrow
passages of complex shapes.  The collage may have visibly lopsided cells.

**Most visible in**: `test_cvt` (uniform frames in an L-shape; without CVT,
cells in the corner drift toward one arm of the L)

---

### L\_fea — One-sided Feasibility Penalty

```
deficit_i = max(0,  0.70 × target_ratio_i  −  area_ratio_i)
L_fea     = sum( (deficit_i / target_ratio_i)² )
```

**Goal**: Penalise cells that fall below **70 % of their target share**.
One-sided: gradient is exactly 0 for cells at or above the floor, so large
cells are never forced to shrink.  Deficit normalised by `target_ratio` makes
gradient magnitude scale-invariant w.r.t. cell count.

**Enabled in**: `full`, `wo_cap`, `wo_cvt`

**Effect of removing (`wo_fea`)**: In narrow shape regions (star tips, crescent
ends), cells can shrink indefinitely.  Tiny cells produce illegible collage
tiles; in extreme cases a cell may vanish entirely.

**Most visible in**: `test_fea` (uniform frames in a thin crescent; without
L_fea, the cells near the crescent tips become very small or disappear)

## Ablation Modes

| Flag | Disabled | Intended observation |
|------|----------|----------------------|
| `full` | — | Baseline: all 3 losses active |
| `--ablation=wo_cap` | L\_cap\_res | Cells ignore saliency → equal sizes |
| `--ablation=wo_cvt` | L\_cvt\_norm | Cells drift → irregular shapes |
| `--ablation=wo_fea` | L\_fea | Narrow-region cells starve |

## Synthetic Test Cases

Generated by `generate_synthetic_test.py`.  Each case is designed to make one
loss's effect clearly visible:

| Case | Mask | Frames | Style | Targets |
|------|------|--------|-------|---------|
| `test_cap` | star | 10 | varying sizes | L\_cap |
| `test_cvt` | L-shape | 12 | equal | L\_cvt |
| `test_fea` | crescent | 8 | equal | L\_fea |
| `test_combined` | donut | 10 | mixed | all 3 |

**Frame counts are conservative** (8–12) to ensure every cell has enough
foreground area and produce clean collages for paper figures.

## Quick Start

```bash
# 1. Generate synthetic test data
cd CAST_loss
python generate_synthetic_test.py

# 2. Run 4-mode ablation on all synthetic cases
./run_ablation_synth.sh
# Results → FINAL_data/layout/ablation_loss_synth_v3/

# 3. Run 4-mode ablation on video datasets + synthetic
./run_ablation.sh
# Results → FINAL_data/layout/ablation_loss_video_v2/
#            FINAL_data/layout/ablation_loss_synth_v2/

# 4. Single run (custom)
python run.py  <mask.png>  <frames_dir>  <output_dir>  2 \
    --shape-is-mask \
    [--filter-frames-by-isnet | --no-filter-frames-by-isnet] \
    [--ablation=wo_cap | --ablation=wo_cvt | --ablation=wo_fea]
```

## Key Hyperparameters (`voronoi_layout.py → CONFIG`)

| Parameter | Default | Role |
|-----------|---------|------|
| `resolution` | 512 | Optimization grid size |
| `num_iterations` | 400 | Gradient-descent steps |
| `w_capacity` | 35.0 | Weight for L\_cap\_res |
| `w_cvt_norm` | 50.0 | Weight for L\_cvt\_norm |
| `w_fea` | 16.0 | Weight for L\_fea |
| `warmup_ratio` | 0.50 | Fraction of iters in Stage 1 (sites only) |
| `core_alpha` | 0.30 | Core quota = 30 % of avg cell area |
| `tau` | 60.0 | Softmax temperature |
| `lr_sites` | 0.01 | Site position learning rate |
| `lr_weights` | 0.02 | Weight learning rate |
